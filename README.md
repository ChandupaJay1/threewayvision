# Three Way Vision (තුන් කල් දැක්ම)

A trilingual React application for the Three Way Vision national master plan, built with Vite and Tailwind CSS.

## Features
- Trilingual support (Sinhala, English, Tamil)
- Responsive design
- Modern UI with glassmorphism effects
- Smooth animations
- Multiple pages: Home, Introduction, Economy, Online Shop, Business Plan, and more!

## Tech Stack
- React + Vite
- Tailwind CSS
- React Router (state-based)

## Installation
```bash
npm install
```

## Development
```bash
npm run dev
```

## Build
```bash
npm run build
```

## Preview
```bash
npm run preview
```
